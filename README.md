# Kafka Learning Lab

An interactive learning site that explains Apache Kafka from first principles. Learn through detailed explanations, visual examples, and hands-on browser simulations—no Kafka installation or account required.

**[Start learning →](https://jsungc.github.io/kafka-learning-lab/)**

## Features

- Beginner-friendly explanations with diagrams and interactive visual guides.
- Step-by-step experiments for event delivery, independent consumers, and recovery.
- Scenario-based exercises with validation, hints, and explanatory feedback.
- Learning progress saved locally in your browser.
- Responsive layouts, keyboard controls, and light/dark themes.

Simulations are simplified educational models, not connections to a real Kafka cluster.

## Development

Built with React, TypeScript, and Vite. Requires Node.js 24.

```sh
npm ci
npm run dev
```

Open `http://localhost:5173/kafka-learning-lab/`.

```sh
npm test       # Unit tests
npm run build  # Production build
```
